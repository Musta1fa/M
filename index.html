القدرات البرمجية الأساسية

معمارية المحرك واستعراض التمرير الأفقي

استمتع بتجربة تثبيت الشاشة وتحويل مسارات التمرير والتحولات الهندسية ذات الإطارات المرتفعة.

01

ScrollTrigger Pinning

تثبيت العناصر في مسار الشاشة مع ربط حركة الخط الزمني بدقة متناهية مع بكسلات التمرير دون حدوث أي وميض أو اهتزاز.

02

MorphSVG & Transforms

تحويل الأشكال الهندسية المتجهة بسلاسة غير مسبوقة مع حساب نقاط التماس وحسابات الاستيفاء البصري الفوري.

03

Flip Plugin Transitions

تسجيل أبعاد العناصر وحالاتها في الذاكرة (FLIP: First, Last, Invert, Play) وتحريكها تلقائيًا بين مواقع الـ DOM المختلفة.

<State: Inverted />
Scale: 1.0 -> Transform
04

Kinetic Split Typography

تفكيك العبارات والكلمات إلى حروف مستقلة وتحريكها بزوايا ثلاثية الأبعاد مع تأثير فك التشفير السيبراني.

[K_I_N_E_T_I_C]
05

Inertia & Physics Spring

محاكاة الجاذبية والاحتكاك وقوة الدفع الحركي التفاعلي مع دعم السحب والإفلات التلقائي.

Velocity: 1420px/s (Damped)

مبني لأعلى معدلات الإطارات 120 FPS

معمارية برمجية خالية من أخطاء الـ Reflow والتسريبات البرمجية، تضمن أسرع وقت استجابة لأي تفاعل.

انعدام التقطيع والـ Layout Thrashing

عزل قراءات أحداث الفأرة عن طبقات الرسم وتطبيق التنعيم الخطي (Lerp) فقط عبر مسار `translate3d` و `opacity` لمنع عمليات إعادة الحساب المكلفة على المعالج المركزي.

تزامن Lenis فائق الدقة

تكامل حلقة التمرير مع GSAP Ticker مباشرة دون أي تأخير زمني أو تعارض مع محرك المتصفح.

مؤشر ذكي متكيف مع اللمس

يتعرف المحرك تلقائياً على شاشات اللمس والهواتف ويوقف المؤشر لتقليل استهلاك البطارية بنسبة 100%.

جاهزية كاملة لـ GitHub Pages ودومين مخصص

هيكلية استاتيكية بدون أي اعتماد على سيرفرات Node.js أو عمليات Build معقدة. ارفع الملفات واستمتع بموقع فائق السرعة عبر CDN عالمي مجاني للأبد.

جاهز للنشر الفوري على GitHub Pages

بدون أي تعقيدات برمجية أو عمليات بناء سيرفرية. ملفات استاتيكية نقية جاهزة للربط مع دومينك المخصص فوراً.

خطوة 01

إنشاء مستودع GitHub

أنشئ مستودعاً جديداً (New Repository) على GitHub باسم مناسب (مثلاً: `gsap-motion-site`).

خطوة 02

رفع ملفات المشروع

قم برفع ملفات (`index.html`, `styles.css`, ومجلد `js/`) مباشرة إلى المستودع (Main Branch).

خطوة 03

تفعيل Pages وإضافة الدومين

ادخل إلى Settings > Pages واضبط المصدر على `Deploy from branch` ثم أضف الدومين الخاص بك في `Custom domain`.
